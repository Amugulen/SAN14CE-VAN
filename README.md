# VAN 三国志14传承版适配候选

面向 Steam 传承版简体中文 1.0.1（6A983905）和 1.0.2（6AD06C1B）的 VAN 离线验证候选。保留原作者 VAN 署名。

## 下载

[下载 v1.2.2 完整包、升级包和校验值](https://github.com/Amugulen/SAN14CE-VAN/releases/tag/v1.2.2)

- 完整包：解压后运行“启动修改器.exe”。
- 升级包：退出 VAN，解压覆盖到“启动修改器.exe”所在目录；保留原有 INI 设置。

v1.2.2 是文件日志诊断候选：增加请求与实际文件路径、系统错误码和失败阶段，定位“黄巾起义以外剧本”读取失败；该问题根因尚未确认，不能视为已修复。保留 v1.2.1 对原生核心覆盖共享加载入口的修正。

## 验证范围

28 组离线回归通过，涵盖两种核心安装顺序和共享/普通剧本/存档读写。真实 VAN/游戏界面、实际进程交互及 1.0.2 新建存档尚未验收，因此发布标记为 Pre-release。
