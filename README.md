# VAN 三国志14传承版适配候选

面向 Steam 传承版简体中文 1.0.1（6A983905）和 1.0.2（6AD06C1B）的 VAN 离线验证候选。保留原作者 VAN 署名。

## 下载

[下载 v1.2.3 完整包、升级包和校验值](https://github.com/Amugulen/SAN14CE-VAN/releases/tag/v1.2.3)

- 完整包：解压后运行“启动修改器.exe”。
- 升级包：退出 VAN，解压覆盖到“启动修改器.exe”所在目录；保留原有 INI 设置。

v1.2.3 修正原生选择器沿用旧版 DLC 目录分类的问题：部分传承版剧本被拼到 DLC/0010_SC，而实际位于 0010_SC，导致找不到文件。修正打开与保存共用的路径分支，升级时需一同覆盖 San14EditorCE_SC.exe。保留详细诊断日志及 v1.2.1 的共享入口修正。

## 验证范围

29 组离线回归通过，含全部50个安装剧本经原生选择入口完整加载、缓存核对、原生保存路径和私有副本原地保存，以及两种核心安装顺序和共享/普通剧本/存档读写。真实 VAN/游戏界面、实际进程交互及 1.0.2 新建存档尚未验收，因此发布标记为 Pre-release。

仓库仅用于发布修改器候选及说明，不包含游戏程序、剧本、存档或私人日志。
