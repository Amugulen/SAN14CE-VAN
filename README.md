# VAN 三国志14传承版适配候选

面向 Steam 传承版简体中文 1.0.1（6A983905）和 1.0.2（6AD06C1B）的 VAN 离线验证候选。保留原作者 VAN 署名。

## 下载

[下载 v1.2.1 完整包、升级包和校验值](https://github.com/Amugulen/SAN14CE-VAN/releases/tag/v1.2.1)

- 完整包：解压后运行“启动修改器.exe”。
- 升级包：退出 VAN，解压覆盖到“启动修改器.exe”所在目录；保留原有 INI 设置。

v1.2.1 修复原生核心晚安装时覆盖共享文件加载入口、触发旧日文乱码提示的问题。
